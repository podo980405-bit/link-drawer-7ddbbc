    휴대폰 ↔ 컴퓨터 동기화 GitHub '열쇠(토큰)'를 휴대폰과 컴퓨터에 각각 한 번씩 넣으면, 같은 목록이 자동으로 맞춰져요. 목록은 내 GitHub 계정의 비밀 저장 공간(비밀 Gist)에만 저장되고, 열쇠는 이 브라우저에만 저장돼요.
    1. 열쇠 만들기 페이지를 열어요. 이름과 권한(gist)이 미리 채워져 있어요.
    2. Expiration(만료)을 No expiration(만료 없음) 또는 1년으로 고르고, 맨 아래 Generate token(토큰 생성)을 눌러요.
    3. 나온 ghp_… 열쇠를 복사해서 위 칸에 붙여넣고 연결을 눌러요. 다른 기기에서도 같은 열쇠를 넣어요.
    인스타·유튜브 게시물 불러오기 (내 중계 서버) 인스타와 유튜브 게시물은 사이트가 직접 읽을 수 없어서 '중계 서버'가 대신 가져다 줘야 해요. 무료 공개 중계 서버는 자주 막혀서, Cloudflare에 나만 쓰는 중계 서버를 무료로 만들어 연결하는 걸 추천해요. 유튜브·인스타 주소만 중계해서 다른 용도로는 쓸 수 없어요.
    1. Cloudflare에 무료로 가입하고 로그인해요.
    2. 왼쪽 메뉴 Workers & Pages(작업자 및 페이지) → Create(만들기) → Start with Hello World!(Hello World로 시작) → Deploy(배포)를 눌러요.
    3. Edit code(코드 편집)를 눌러 원래 있던 코드를 모두 지우고, 아래 중계 서버 코드 복사로 복사한 코드를 붙여넣은 뒤 Deploy(배포)를 눌러요.
    4. 화면 위쪽의 https://…workers.dev 주소를 복사해서 위 칸에 붙여넣고 연결을 눌러요.
    유튜브 영상 설명으로 요약 자동 채우기 무료 YouTube API 키를 넣으면 각 영상 설명을 읽어서 무슨 내용인지 짧게 적어 주고, 분류도 더 정확해져요. 키는 이 브라우저에만 저장돼요.
    1. Google Cloud 콘솔에 로그인해서 프로젝트를 하나 만들고 YouTube Data API v3를 사용으로 켜요.
    2. 사용자 인증 정보에서 사용자 인증 정보 만들기 → API 키를 눌러 나온 키를 복사해 위에 붙여넣어요.
    3. 하루 1만 회까지 무료고, 영상 50개를 한 번에 1회로 처리해서 개인용으로는 돈이 들지 않아요.
