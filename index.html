유튜브 영상 설명으로 요약 자동 채우기 무료 YouTube API 키를 넣으면 각 영상 설명을 읽어서 무슨 내용인지 짧게 적어 주고, 분류도 더 정확해져요. 키는 이 브라우저에만 저장돼요.
  1. Google Cloud 콘솔에 로그인해서 프로젝트를 하나 만들고 YouTube Data API v3를 사용으로 켜요.
  2. 사용자 인증 정보에서 사용자 인증 정보 만들기 → API 키를 눌러 나온 키를 복사해 위에 붙여넣어요.
  3. 하루 1만 회까지 무료고, 영상 50개를 한 번에 1회로 처리해서 개인용으로는 돈이 들지 않아요.
